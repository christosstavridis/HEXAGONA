# HEXAGONA v1.0.0

## Overview

**HEXAGONA v1.0.0** marks the first structured, versioned release of the project.

This release establishes the core system architecture, workflows, and visual language
that future versions will build upon. HEXAGONA is intended as a long-term playground
for procedural exploration, iteration, and learning.

---

## Features

### Board & Tile System
- Hexagon-based board layout with global control over scale and structure
- Per-tile variation and configuration

### Terrain & Water
- Procedural landscape shaping
- Integrated sea generation with configurable level and appearance
- Optional high-quality mesh generation
- Clean, unwrapped UVs for texturing workflows

### Color & Materials
- Six built-in color palettes
- Fully art-directable color workflows
- Mesh groups for flexible material assignment

### Scattering & Set Dressing
- Integrated foliage and rock scattering
- Support for user-provided meshes
- Height-, noise-, and density-driven distribution

### User Inputs
- Custom heightmaps and colormaps
- User-defined meshes and color data

### Integration
- Houdini Engine compatible

---

## Notes

- This release establishes the public baseline for HEXAGONA.
- Future releases may introduce new features, refinements, and optimizations.
- Breaking changes, when introduced, will be clearly documented and versioned accordingly.
